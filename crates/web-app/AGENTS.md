# web-app

> Auto-loaded when you work in this subtree (not a cargo member — the
> Vite + TS host). Font channel: docs/agents/fonts.md §web channel; local
> details in this crate's `README.md`.

The Vite + TS host app integrating `@office-rs/rofd` (=
`crates/web-view/sdk`).

```bash
npm run build:sdk   # wasm-pack build ../web-view --target web -> sdk/dist
npm run dev         # vite dev server
npm run build       # production build
npm run smoke:nogpu # no-GPU smoke (headless Chrome --disable-gpu must land in the CPU fallback)
```

- `public/fonts/` is a local font test directory (**gitignored**; absent in
  a fresh clone, never distributed); `public/fonts-sliced/` holds the six
  commercial families' local slices (gitignored; generated by
  `D:/code/fonts/tools/slice.py`).
- e2e: `e2e/` + playwright.config.ts (the convert-wasm demo depends on the
  Playwright install here).
- Transitional dep: the SDK's `file:` font package needs a sibling checkout
  of `D:/code/fonts` (switch to `^1.0.0` once the npm package ships, then
  drop this note).
