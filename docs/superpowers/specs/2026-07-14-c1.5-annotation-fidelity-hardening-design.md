# rofd C1.5：批注保真补缺 设计

- **日期**: 2026-07-14
- **状态**: Draft（待评审）
- **范围**: V1 收尾插项 -- 修复 `test/sample.ofd`（14 种批注）揭示的 C1 模型与真实 OFD 的保真偏差
- **前置**: Cluster 1（io 批注往返 GB/T 33190 合规）已完成。C1.5 是 C1 的保真硬化（非新功能）
- **触发**: 用户添加 `test/sample.ofd`（含普通文本 + 全部 14 种批注类型），分析揭示 C1 模型 6 处偏差
- **后续**: C1.5 完成后回 Cluster 3（交互式批注 UX）

---

## 1. 背景与动机

C1 实现了批注 io 的 GB/T 33190 合规（Type+Subtype、Appearance、手术刀保存），但 C1 的模型基于**假设**的 Type 枚举 {Link, Path, Highlight, Stamp, Watermark}（来自 ofdrw，不全）。`test/sample.ofd` 揭示真实 OFD 还有：

- **`Type="FreeText"`**（文字批注 TypeWriter / 文本框 FreeText）-- C1 的 `map_type_subtype` 无此 Type，**错解析成 Highlight**。rofd 的 TextBox 序列化用 `Type=Path Subtype=TextBox` 也错（标准是 FreeText）。
- **手写 = `Type=Stamp Subtype=Pen` + ImageObject**（笔迹光栅化成图）-- rofd 的 Freehand 是路径，不匹配；解析真实手写无 Pen 处理。
- **Polygon / PolyLine**（`Type=Path Subtype=Polygon/PolyLine`）-- rofd ShapeKind 缺这两种。
- **椭圆用 A 圆弧**（`M...A...A...A...A...`）-- rofd `ellipse_path` 用 C 贝塞尔，`path_to_abbrev` 丢 A。
- **Squiggly 被降级** -- C1 把 `Subtype=Squiggly` 降级成 Highlight（应精确 Squiggly）。
- **箭头 = 线+填充三角头**（EndCap=Solid, Fill=true）-- rofd `arrow_path` 是线+两短线。
- **富 Parameters 丢弃** -- Vertices（形状顶点）、AllRichText（文字 HTML）等，C1 只读 CreationDate/InReplyTo。

**后果**：`sample.ofd` 的文字批注/文本框被错解析（Highlight），Polygon/PolyLine/Pen 无对应模型，椭圆/箭头渲染不符，Squiggly 丢失。C1.5 修复这些保真偏差，让 rofd 能正确 parse/render 全部 14 种真实批注。

## 2. 范围与成功标准

### 2.1 范围（in）

- **FreeText 类型**：parse `Type=FreeText` -> TextBox；serialize TextBox -> `Type=FreeText Subtype=FreeText`。
- **Squiggly kind**：加 `AnnotationKind::Squiggly`；parse `Subtype=Squiggly` -> Squiggly（不降级）；serialize；render 波浪 Q 曲线。
- **椭圆 A 圆弧**：`ellipse_path` 用 A；`path_to_abbrev` 发 A。
- **Polygon / PolyLine**：ShapeKind 加两种；`Shape` payload 加 `points: Vec<Point>`；parse Vertices 参数；serialize + render。
- **Pen -> Stamp**：parse `Type=Stamp Subtype=Pen` -> Stamp（图片）。
- **箭头填充三角**：`arrow_path` 改主线+填充三角头。
- **Vertices 参数**：parse（Polygon/PolyLine 顶点）。
- **sample.ofd `#[ignore]` 测试**：14 种 parse + body 字节保留。

### 2.2 范围（out / 推迟）

- AllRichText / ParagraphFormat / GrowMode / UnderlineType / Pentype / EndCap 等富参数（Remark + Appearance TextObject 的 font/size/color 够 v1）。
- Note 的 Type=FreeText 映射（样本无 Note；Note 保持 `Type=Path Subtype=Note`）。
- rofd 创建 Pen（手写创建是 C3，用 Freehand 路径）。
- body 文本 CGTransform/Glyphs（body 渲染范畴，非批注）。
- Ellipse/Arrow/Line 等的 Vertices 参数（rofd 用 rect 算几何，Vertices 冗余；只 Polygon/PolyLine 需 Vertices）。

### 2.3 成功标准

- `sample.ofd` parse -> 14 批注解析到正确 kind+payload（无错解析成 Highlight）。
- `sample.ofd` surgical save -> body `Content.xml` 字节级保留 + 批注条目标准结构重写。
- 逆往返：FreeText(TextBox)、Squiggly、Polygon、PolyLine、Ellipse(A 弧) 各 serialize->parse->全等。
- 椭圆/箭头 render 符合真实 OFD 几何（A 弧 / 填充三角）。

## 3. 设计

### 3.1 FreeText 类型（最关键）

**parse**（`crates/io/src/parse/annotation.rs` 的 `map_type_subtype`）：
- `Type="FreeText"`（任意 Subtype：TypeWriter / FreeText / 未知）-> `AnnotationKind::TextBox`。
- Appearance TextObject -> TextBox payload（content=TextCode 文本, font=Font, size=Size, color=FillColor, rect=Appearance Boundary）。
- `Remark` 作 content 备份（无 TextObject 时用 Remark）。

**serialize**（`crates/io/src/serialize/annotation.rs` 的 `kind_to_type_subtype`）：
- `TextBox` -> `("FreeText", Some("FreeText"))`（改 C1 原 `("Path", Some("TextBox"))`）。
- Appearance 仍发 TextObject（content/font/size/color/rect）。

**Note**：保持 `Type=Path Subtype=Note`（rofd 专有 popup，样本无 Note，不改）。

### 3.2 Squiggly kind（不再降级）

**dom**：`AnnotationKind` 加 `Squiggly` variant（Markup payload 复用：quad_points + color）。

**io parse**：`("Highlight", Some("Squiggly"))` -> `Squiggly`（改 C1 降级 Highlight）。`build_payload`：Squiggly 走 Markup 分支。

**io serialize**：`Squiggly` -> `("Highlight", Some("Squiggly"))`。

**render**：`draw_squiggly`（在 annotation_scene 或 annotation_geom）-- 画波浪 Q 曲线（如样本：quad_points 区域内交替上下 Q 曲线）。

### 3.3 椭圆 A 圆弧

**`annotation_geom::ellipse_path`**（`crates/io/src/annotation_geom.rs`）：
- 改用 A 圆弧（4 段），匹配真实样本 `M cx+rx cy A rx ry 0 0 1 cx cy+ry A rx ry 0 0 1 cx-rx cy A ... A cx+rx cy`。
- 注：OFD 的 A 弧参数 6 个（rx ry rot large-arc sweep x y）。

**`path_to_abbrev`**（serialize/annotation.rs）：
- `PathCommand::A(a,b,c,d,e,f)` -> `"A a b c d e f"`（C1 原丢弃，现发出）。

**parse**：`parse_abbreviated` 已支持 A（C1）。

### 3.4 Polygon / PolyLine

**dom**：
```rust
pub enum ShapeKind { Rect, Ellipse, Arrow, Line, Polygon, PolyLine }  // 加两种

pub enum AnnotationPayload {
    Shape { kind: ShapeKind, rect: Rect, stroke: Color, fill: Option<Color>, width: f64, points: Vec<Point> },  // 加 points
    // ... 其他不变
}
```
- Rect/Ellipse/Arrow/Line：points 空（用 rect 算几何）。
- Polygon/PolyLine：points 填顶点。

**io parse**：
- `("Path", Some("Polygon"))` -> `Shape{kind=Polygon, rect=Boundary, points=Vertices 参数解析, stroke/fill/width}`。
- `("Path", Some("PolyLine"))` -> `Shape{kind=PolyLine, ...}`。
- Vertices 参数：空格分隔的 `x y x y ...` -> `Vec<Point>`。

**io serialize**：
- Polygon -> PathObject AbbreviatedData `M p0 L p1 L p2 ... Z`（闭合）+ Vertices 参数。
- PolyLine -> `M p0 L p1 L p2 ...`（不闭合，无 Z）+ Vertices 参数。

**render**（annotation_scene）：Shape.points 非空时按顶点画多边形（闭合填充/描边）/折线（描边）；points 空时按 rect 算（现有 Rect/Ellipse/Arrow/Line）。

### 3.5 Pen -> Stamp

**io parse**：`Type="Stamp" Subtype="Pen"` -> `Stamp` kind（ImageObject -> image=ResourceID, rect=Boundary）。Subtype=Pen 忽略（当图片章处理）。

**serialize**：Stamp -> `Type="Stamp"`（不变，rofd 不创建 Pen）。

**render**：Stamp 渲染图片（已有）。

### 3.6 箭头填充三角头

**`annotation_geom::arrow_path`**：
- 改为主线 `M x0 y0 L x1 y1` + 填充三角箭头头 `M hx0 hy0 L hx1 hy1 L hx2 hy2 C`（三角，Fill=true）。
- 箭头头在终点（x1,y1），方向沿主线，大小 = `min(w,h)*0.25`（如 C1 原 arrow_path 的 head 比例）。
- 匹配样本 `M 65.7342 128.3311 L 67.1096 127.2268 L 65.3795 126.883 C M 67.1096 127.2268 L 35.9894 134.8477`（三角 + 主线）。

**Shape Arrow 的 fill**：arrow_path 的三角用 fill（rofd Shape Arrow 的 fill 字段；创建时 fill=Some(stroke color) 或默认）。

### 3.7 Vertices 参数

**parse**：`Parameters` 里 `Name="Vertices"` -> 解析 `x y x y ...` -> `Vec<Point>`（Polygon/PolyLine 用；其他形状忽略）。
**serialize**：Polygon/PolyLine 发 Vertices 参数（顶点列表）。
**保留**：CreationDate/InReplyTo（C1）。

### 3.8 sample.ofd 测试夹具

`crates/io/tests/sample_ofd.rs`（新，`#[ignore]`）：
- `parse_ofd(test/sample.ofd)` -> 断言 14 批注：
  - Page 0: Highlight(Highlight), Underline, Strikeout, Squiggly, Stamp(Pen->Stamp), Line, Arrow, Rect, Ellipse, Polygon, PolyLine, TextBox(TypeWriter), TextBox(FreeText), Stamp.
  - Page 1: Stamp.
- 断言关键 payload：TextBox content（"文字批注内容"/"文本框内容"）；Polygon/PolyLine points 非空；Stamp image；Squiggly kind。
- `save_ofd` -> body `Content.xml` 字节级保留 + 批注条目标准结构。

### 3.9 错误处理

- 无新硬错（保真修复，不 fatal）。
- 未知 Subtype/Parameter -> 跳过/默认（不 fatal，C1 §4.6）。
- Vertices 解析失败 -> points 空（Polygon/PolyLine 降级，+ warning 留 Cluster 4）。
- 无裸 unwrap。

## 5. caveat / 不在范围

- **AllRichText/ParagraphFormat**：文字批注的富文本格式（HTML/JSON）丢弃，只留 Remark 纯文本 + Appearance TextObject 的 font/size/color。富文本编辑后置。
- **Note 映射**：Note 保持 `Type=Path Subtype=Note`（rofd 专有 popup）。若未来真实 OFD 有 Note 样本，再确认映射。
- **Pen 创建**：rofd 不创建 Pen（手写创建是 C3，用 Freehand 路径）。rofd 解析真实 Pen -> Stamp（图片），rofd 创建的手写是 Freehand（路径）--两种表示都合法，但不同。
- **Ellipse/Arrow/Line 的 Vertices**：rofd 用 rect 算几何，Vertices 冗余（忽略）。只 Polygon/PolyLine 用 Vertices。
- **body CGTransform/Glyphs**：body 文本的字形映射（非批注），不改。

## 6. 决策记录

| # | 决策 | 理由 |
|---|---|---|
| 1 | FreeText(both subtypes) -> TextBox | 都是文字+rect+font/size；边框是渲染细节 v1 不建模；Note 不匹配（非 popup） |
| 2 | 加 Squiggly kind（不降级） | 样本有 Squiggly；降级 Highlight 丢语义；从 C3 挪来（保真修复） |
| 3 | 椭圆用 A 圆弧 | 匹配真实样本；path_to_abbrev 发 A（原丢） |
| 4 | Shape 加 points（非新 payload 变体） | 一个 payload 变体，改动小；Rect/Ellipse/Arrow/Line 的 points 空 |
| 5 | Pen -> Stamp | 图片保留渲染正确；Pen kind 与 Stamp 重复；rofd 创建手写用 Freehand（C3） |
| 6 | 箭头填充三角 | 匹配真实样本（EndCap=Solid, Fill=true） |
| 7 | Vertices 只 Polygon/PolyLine | 其他形状用 rect，Vertices 冗余 |
| 8 | 推迟 AllRichText/ParagraphFormat | Remark + Appearance TextObject 够 v1 |
| 9 | sample.ofd `#[ignore]` | gitignored 真实样本，CI 跳、本地跑 |

## 7. 对 C1 spec 的修订

- **§3.4 AnnotType 枚举**：补 `FreeText`（C1 原只 {Link, Path, Highlight, Stamp, Watermark}，ofdrw 不全）。
- **§5 Type+Subtype 映射**：TextBox -> `Type=FreeText Subtype=FreeText`（改原 Type=Path）；加 Squiggly -> `Type=Highlight Subtype=Squiggly`（不降级）；加 Polygon/PolyLine -> `Type=Path Subtype=Polygon/PolyLine`；Pen -> Stamp。
- **§3.2 AnnotationPayload**：Shape 加 `points: Vec<Point>`；ShapeKind 加 Polygon/PolyLine；AnnotationKind 加 Squiggly。
- **§6.4 Appearance 几何**：ellipse 用 A 弧；arrow 填充三角；polygon/polyline 从 points。
