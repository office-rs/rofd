## 1. 打开与渲染

- [ ] `cargo run -p gpui-app -- test/ru-yuan-ji-lu.ofd` → 打开即渲染，状态栏显示「已打开 …（N 页）」
- [ ] 无参数启动 → 空白编辑器（页签「批注文稿1」），不崩溃、无报错
- [ ] 正文文字/线条在 100% 与 150%+ DPI 下锐度可接受（对照 xilem-app 同文档）
- [ ] 文档声明字体经系统字体通道懒加载命中（宋体/黑体等本机族渲染正确；未装族回退默认字体不报错）

## 2. 滚轮与缩放

- [ ] 滚轮逐档滚动：一格约一行（20px 手感，与 xilem-app 对齐），方向正确（上滚向上）
- [ ] 触控板双指滚动（Pixels 通道）方向正确
- [ ] ctrl+滚轮：以指针位置为锚缩放（指针下文档点不漂移）；上滚放大
- [ ] ctrl+滚轮连续缩小到下界后继续缩 → 值不再变化、且**不**退出 fit 模式（若先选了适应模式）
- [ ] 先 fit 到低于 25% 的档位再手动放大/缩小 → 无跳变（动态下限放宽到 5%）
- [ ] 失焦/后台窗口 → 光标闪烁停止（无空转动画帧）

## 3. IME（批注文本编辑）

前置：双击某批注进入文本编辑（caret 出现）。

- [ ] MS 拼音：输入 nihao → preedit 内联显示 → 空格上屏「你好」（**回归：不得残留拼音**，ime.rs replace_text(final) 同步 preedit 路径）
- [ ] MS 拼音：数字键选第 2/3 候选 → 上屏对应词
- [ ] 搜狗输入法：同上两项
- [ ] Esc 取消组合 → 无残留（cancel 路径）
- [ ] unmark 确认路径：组合中点击工具条按钮/切换窗口 → 组合文本 force-commit（不悬空）
- [ ] 组合中连续输入多段 → 每段独立上屏
- [ ] 候选窗锚定在 caret 处（不是工具栏高度偏上——bounds_for_range + element_origin）
- [ ] 英文直接键入 "hello" → 恰好一次/字符（无双写，双通道防双写回归）
- [ ] Shift+字母 → 大写正确；Ctrl+字母快捷键不被文本通道吞掉

## 4. 右键菜单（R7 严格 web 对齐）

- [ ] 右键命中**批注** → 弹出菜单，唯一项「删除批注」；点击 → 批注删除、状态栏「已删除批注」
- [ ] 右键命中**页面空白/桌面** → 不出菜单
- [ ] 菜单弹出后点击其他处 → 关闭；光标移动（CursorChanged）也关闭
- [ ] 键盘 Del/Backspace：选中批注（非编辑态）→ 删除选中

## 5. 多文档会话

- [ ] 「+」页签 → 新建空白（批注文稿2）并聚焦；每会话独立滚动/缩放/光标
- [ ] 再开一个 .ofd 文件 → 新页签激活，文件名去扩展名
- [ ] 切换页签 → 状态栏页码/zoom/工具选中态跟随各自会话；打开的下拉/右键菜单/确认框被复位
- [ ] 关闭**已修改**会话 → 确认框（保存/不保存/取消）：保存走保存流后关闭；不保存直接关；取消保留
- [ ] 关闭**未修改**会话 → 直接关闭
- [ ] 关闭最后一个会话 → 自动新建空白
- [ ] 关闭当前焦点会话后 → 键盘/IME 无需点击即可用（焦点修复）

## 6. 文件保存链

- [ ] 加高亮批注 → Ctrl+S → 状态栏「已保存」、● 未保存消失；重开该文件 → 批注在（annotations survive）
- [ ] 重开后的文件与原始包 diff：未触碰条目字节级不变（手术刀；io 测试守护，宿主只验通路）
- [ ] 「另存为」→ 新路径保存成功 → 页签改名、后续 Ctrl+S 写新路径
- [ ] 空白文档（无路径）Ctrl+S → 弹另存为对话框
- [ ] 「导出为 PDF」→ 生成的 PDF 可打开、页数正确、净版预设（无水印无批注、有图章）
- [ ] 打开对话框取消 → 无副作用

## 7. 打印

```bash
cargo run -p gpui-app --example print_to_file -- test/ru-yuan-ji-lu.ofd target/print-probe.out
```

- [ ] 示例通道：退出码 0，输出 `job state: Done` 且 target/print-probe.out 非空（Microsoft Print to PDF 为默认打印机时为 PDF）
- [ ] 宿主「打印…」：对话框打开 → 先「正在查找打印机…」后列出打印机；纸型/方向默认取文档首页
- [ ] 全字段可编辑：打印机循环、份数 ±、逐份、双面、彩色、纸型 7 项、方向 3 项、范围 All/Current/Custom（如 1-3,5）、奇偶
- [ ] 内容三开关（水印/批注/图章）默认净版+图章；勾选批注后打印结果含批注
- [ ] Custom 范围非法（如 1-3,x）→ 状态行列错误、提交被阻
- [ ] **无打印机态**（停 Spooler 服务）：显示「未找到打印机」，提交被阻
- [ ] 提交 → 「已发送到打印机」；提交期间再点提交 → 无重复作业（单轨）
- [ ] 提交后立即取消/关闭面板/切换页签 → 任务被撤（打印队列无残留）
- [ ] 失败态（断开打印机）→ 状态行「打印失败: …」且可重试

## 8. 工具栏功能面

- [ ] 手型：拖动平移、指针变 OpenHand/ClosedHand；文本：指针变 IBeam
- [ ] markup 四按钮：无正文选区时禁用；选中正文文字后点击 → 高亮/下划线/删除线/波浪线各自生效
- [ ] 高亮取色器：选色即改默认色；**有选区时选色立即应用一条高亮**（R4）
- [ ] 手绘：自由曲线批注
- [ ] 图形下拉六种：矩形/椭圆/直线/箭头/多边形/折线逐个可画，触发按钮随选择改名
- [ ] 撤销/恢复按钮：随历史使能/禁用；Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z 同效
- [ ] zoom 菜单：适应宽度/高度/页面三模式 ✓ 态正确；预设 10%~500% 逐档点击值正确、状态栏 % 跟随

## 9. 剪贴板

- [ ] 选中正文文字 Ctrl+C → 粘贴到记事本得纯文本
- [ ] Ctrl+X → 与 Ctrl+C 同（copy-only，绝不删除任何内容）
- [ ] 批注编辑态 Ctrl+V → 文本插入 caret 处；记事本中文/英文均可

## 10. 全屏与自动翻页

- [ ] 「全屏」按钮 → 窗口全屏、按钮变 active；**Esc 退出**（含全屏中开过下拉再 Esc 的路径）
- [ ] 「自动翻页」→ 每 3s 下翻一页、按钮 active；再点停止
- [ ] 自动翻页进行中切换页签 → 旧文档停止翻页（generation token）、新会话不受影响
- [ ] 自动翻页进行中关闭会话 → 停止

## 11. 警告条

- [ ] 打开含降级项的 OFD（如引用未支持特性/缺资源）→ 底部黄色警告条出现（条数 + 摘要 + 中文文案）
